Spelling Tutor

Scans a photo of handwritten homework, finds the spelling mistakes, and turns them into games

A parent-facing tool: take a photo of a kid's handwritten spelling homework, and Claude's Vision API reads it, finds the misspelled words, and turns them into interactive practice games — no manual grading required. Built as a full-stack app with Vercel Edge Functions handling the API calls securely, so the Anthropic key never touches the browser.

Screenshot coming soon

1. Built the Vision Pipeline

A photo gets base64-encoded in the browser and sent to a Vercel Edge Function, which forwards it to Claude along with a prompt asking it to find misspelled words and return them as structured JSON — each one with the word as written, the correct spelling, and the full sentence it appeared in for context.

Keeping the Anthropic API key server-side in the Edge Function (rather than calling Claude directly from the browser) means the key is never exposed in the page source — the same pattern later reused for the portfolio's own recruiter chatbot concept.

2. Hit the Real Wall: Kids' Handwriting

accuracy problem

The first version used Claude Haiku for speed, but handwriting recognition on messy, inconsistent kid handwriting was rough — a lot of misreads. Fixed it in stages rather than one big swap:

  • Upgraded from Claude Haiku to Claude Sonnet for meaningfully stronger vision performance
  • Added image preprocessing — increasing contrast and sharpening the photo before sending it — to give the model a cleaner image to work from
  • Tightened the prompt to explicitly tell the model to be careful and deliberate reading handwriting, not just fast

Even after those three changes, accuracy still wasn't perfect on genuinely messy handwriting — a real, open tradeoff between a two-pass approach (transcribe the whole page first, then spell-check the clean transcript separately) and bringing in a dedicated OCR tool like Google Cloud Vision's handwriting mode, which trades simplicity (one API) for accuracy (a purpose-built handwriting model).

3. Built Four Game Modes

Once the misspelled words are identified, they get turned into practice, not just a graded list — type-it-out, multiple choice, unscramble, and fill-in-the-blank, all pulled from the words the app actually found rather than a generic word list.

4. Added Printable Worksheets

Beyond the on-screen games, a worksheet generator produces a printable page with three sections: write each word three times (with handwriting lines), fill-in-the-blank using the real sentence context from the original homework, and a word search puzzle built from the same word list. A "Save as PDF" option opens the worksheet and triggers the browser's print dialog, where choosing "Save as PDF" as the destination exports it directly.

Result

Photo of homework → Claude Vision finds misspelled words → four practice game modes, plus a printable worksheet

A parent can go from a photo of messy handwritten homework to a set of ready-to-play spelling games and a printable worksheet in seconds — no manual transcription or grading required.
